## 📖 About

This repository is a **30-day HTML learning challenge** designed to take you from the basics of HTML all the way to your first steps into CSS. Each day focuses on one concept, with its own folder containing a short description, starter code, and hints — so you can learn by actually building, one small step at a time.

Whether you're a complete beginner or brushing up your fundamentals, this challenge is built to help you form a daily coding habit and steadily grow your web development skills.

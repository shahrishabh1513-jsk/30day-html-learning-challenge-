## 📖 About

This repository is a **30-day HTML learning challenge** designed to take you from the basics of HTML all the way to your first steps into CSS. Each day focuses on one concept, with its own folder containing a short description, starter code, and hints — so you can learn by actually building, one small step at a time.

Whether you're a complete beginner or brushing up your fundamentals, this challenge is built to help you form a daily coding habit and steadily grow your web development skills.

## 📂 Project Structure

Each folder is named after the day and challenge topic, and contains the HTML file(s) for that day's task:

```
30day-html-learning-challenge-/
├── 01. Basic HTML Page/
├── 02. Add an Image to your HTML Page/
├── 03. Create a hyperlink to another website/
├── ...
├── 30.  Introduction to CSS/
└── README.md
```

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/shahrishabh1513-jsk/30day-html-learning-challenge-.git
   ```
2. Open any day's folder in your favorite code editor
3. Open the `.html` file in your browser to see it in action
4. Read the hints, tweak the code, and make it your own!
